claim ships.

An agentic scene room for scripted production. The crew writes the scene, then holds it to account: every checkable claim verified against the open web, contested history refused rather than settled, every decision appended to a ledger. The output is a production-ready scene plus its provenance record.

The problem · and the part everyone skips

Any model with a search tool

  • Tells you a claim looks wrong
  • Rules on it — including live disputes
  • Leaves nothing behind to audit
  • Does not write anything

    • Sceneroom

  • Writes the scene, then makes it prove itself
  • Refuses to rule on contested history — routes it to a named human
  • Appends every call: source, decider, reason
  • Re-checks the fix, so a correction cannot smuggle in a new error

    • One pass · about thirty seconds, streamed while it happens

    Four verdicts — the third one is the product

    verified
    Sources support it as written.
    contradicted
    Sources disagree with the scene. A person decides what happens to it.
    contested
    Credible sources disagree with each other. The system states both positions and rules on neither.
    unverifiable
    Nothing found either way. Recorded as unsupported, never as true.
